03 / CHORDS AS VERTICES

One graph. Different paths.

24 vertices · 36 edges

Each vertex is a major or minor triad. An edge is one P, L, or R transformation. Larger vertices occur in the progression; darker edges trace one shortest route between successive chords.

Keyboard: Tab enters each graph. Arrow keys browse triads in chromatic root order (major then minor); Home/End jump to the first/last. P, L, or R follows that transformation. Enter or Space inspects a vertex. Tab leaves the graph.

All panels use the same illustrative coordinates. Count edges to measure distance; physical spacing is not a musical distance. The panels share the first song’s transposition frame.

Select a vertex to inspect its pitch classes and neighbors.

04 / PAIRWISE COMPARISON

How far apart are the progressions?

Each cell is the average P/L/R cost along a dynamic time warping (DTW) alignment. Lower values mean less harmonic transformation. Select a cell to inspect the calculation.

Rows are references; columns are candidates. The inherited algorithm can give different scores in opposite directions when optimal paths tie.

05 / OPEN THE CALCULATION

The alignment, step by step

c(i,j) = dG(aᵢ, Tₖ(bⱼ))
D(i,j) = c(i,j) + min{D(i−1,j), D(i,j−1), D(i−1,j−1)}

Boundary conditions: D(0,0) = 0; D(i,0) = D(0,j) = ∞ for positive indices. Displayed chord positions start at 1.

Outlined cells form the chosen DTW path. Repeated row or column positions allow sequences of different lengths to align.

06 / THE MATHEMATICAL MODEL

From pitch classes to comparison

Represent pitches in ℤ₁₂: C = 0, C♯ = 1, …, B = 11. A major triad at root r is {r, r+4, r+7}; a minor triad is {r, r+3, r+7}, with arithmetic modulo 12.

OperationMajor (r,+) →Minor (r,−) →
P · parallel(r,−)(r,+)
L · leading-tone exchange(r+4,−)(r+8,+)
R · relative(r+9,−)(r+3,+)

Each transformation preserves two pitch classes and is its own inverse. The resulting triad graph has 24 vertices, degree 3, and 36 undirected edges. It represents triad relationships associated with the Tonnetz.

Chord distance dG is the minimum number of edges between two triads, found by breadth-first search. DTW uses those distances to align whole progressions in O(nm) time once chord distances are cached. Across-key mode evaluates all 12 candidate transpositions.

The engine first minimizes total alignment cost, then divides by the chosen path length. It selects the transposition with the lowest resulting average. Similarity = 1/(1 + distance) is a structural score, not a probability.
