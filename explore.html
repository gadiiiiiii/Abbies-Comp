About Tonnetz

Compare major and minor chord sequences using a graph of 24 triads. Each edge is one parallel (P), leading-tone (L), or relative (R) transformation.

Dynamic time warping aligns the sequences. Similarity = 1 / (1 + average alignment cost). Across-key mode checks 12 transpositions.

The hexagonal map repeats boundary chords. Copies refer to the same triad and play the same notes. Each visible edge is one P/L/R transformation. Brighter edges trace shortest paths between successive input chords. Distance is counted in edges, not screen space.

Audio previews are synthesized triads. Examples are chord sequences, not recordings. Scores describe harmonic structure, not musical taste.
